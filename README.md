# Project SISTEM RESERVASI KLINIK INFORMASI - RPL - KELOMPOK 1
Sistem Informasi Klinik dan Reservasi merupakan aplikasi berbasis web yang dirancang untuk membantu pengelolaan administrasi klinik, pendaftaran pasien, reservasi jadwal konsultasi, serta pengelolaan antrean secara digital.

Sistem ini dikembangkan untuk mengatasi permasalahan pendaftaran pasien yang masih dilakukan secara manual, antrean yang tidak terkelola, kesulitan dokter dalam melihat jadwal konsultasi, serta pencatatan hasil pemeriksaan yang belum terintegrasi.

Dengan adanya sistem ini, proses pelayanan klinik diharapkan menjadi lebih terstruktur, efisien, dan mudah diakses oleh setiap pengguna.

# Tech Stack
- Arsitektur: MVC (Model-View-Controller) — PHP Native
- Frontend: HTML5, CSS (Desain UI/UX via Figma)
- Backend: PHP 8.x (OOP / Procedural Terstruktur)
- Database: MySQL Server (XAMPP)
- Tools & Kolaborasi: Google Antigravity, Git & GitHub

# Tujuan Pengembangan
- Mempermudah pasien dalam melakukan registrasi dan reservasi konsultasi secara online.
- Mengelola nomor dan status antrean pasien secara otomatis.
- Memudahkan dokter dalam melihat jadwal konsultasi harian.
- Membantu petugas pendaftaran dalam mengelola data dan antrean pasien.
- Menyimpan hasil pemeriksaan dan riwayat kunjungan pasien secara digital.

# Fitur
1. Manajemen Akun
- Registrasi dan login pengguna.
- Autentikasi berdasarkan peran pengguna.
- Pengelolaan akun oleh admin.

2. Reservasi Online
- Pasien dapat memilih dokter, tanggal, dan jam konsultasi.
- Sistem memeriksa ketersediaan kuota jadwal.
- Reservasi ditolak apabila jadwal sudah penuh.
- Pasien dapat membatalkan atau mengubah reservasi.

3. Manajemen Antrean
- Pembuatan nomor antrean otomatis.
- Informasi status antrean pasien.
- Check-in pasien oleh petugas pendaftaran.

5. Manajemen Dokter
- Pengelolaan jadwal konsultasi dokter.
- Menampilkan daftar konsultasi harian.
- Pencatatan hasil pemeriksaan pasien.

5. Riwayat Pemeriksaan
- Menyimpan hasil pemeriksaan pasien.
- Menampilkan riwayat kunjungan.
- Menghubungkan data pemeriksaan dengan pasien terkait.

6. Laporan
   
Menyediakan laporan kunjungan pasien berdasarkan periode tertentu.
